# Ingredient thumbnails — "Composez votre plat" Step 2

The builder's supplement cards look for a small square thumbnail per option.
Until a file exists, the card shows an elegant gold monogram placeholder, so
nothing breaks. Drop these 6 files here (square, ~200×200, dark background,
warm lighting to match the dishes) to replace the monograms:

| File | Supplement |
|------|------------|
| `truffe.webp`  | Truffe noire du Périgord |
| `foie.webp`    | Escalope de foie gras poêlé |
| `caviar.webp`  | Caviar Osciètre |
| `homard.webp`  | Médaillon de homard bleu |
| `or.webp`      | Feuille d'or comestible |
| `accord.webp`  | Accord mets & vin (2 verres) |

Base (Step 1) thumbnails already use existing images (the clicked dish for
"À la carte", and detail-table / detail-bar / interior-hall for the menus).
Paths/prices are edited in `src/config/composeOptions.js`.
